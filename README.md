# Electromagnetic-Field-Simulation
Numerical simulation of the electromagnetic field generated by two square current loops using the Biot–Savart law.

Description

This project models the magnetic field distribution produced by two parallel square loops carrying alternating currents. The simulation calculates magnetic field components in the central plane between the loops and visualizes the resulting field structure.

The magnetic field is computed by discretizing current-carrying wire segments and summing their contributions according to the Biot–Savart law.

Features
2D magnetic field maps
Vector field visualization
Field intensity normalization
Cross-sectional field analysis
Configurable loop geometry
